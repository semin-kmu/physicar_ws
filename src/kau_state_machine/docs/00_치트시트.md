# 00. 현장 치트시트

대회장·실차 디버깅용 **1페이지**. 상세는 `01`~`10`.

> ⚠ **타 파트 토픽명·노드명·주기는 아직 미정.** 아래 표의 해당 항목은 가정값 (`07` section 2-3, `08` section 4-0)

<br>

## System 상태 7종

| 상태 | `/state_machine/enable` | `/state_machine/speed_limit` | 차량 |
| --- | --- | --- | --- |
| `INIT` | 미발행 | 0 | 정지 |
| `STANDBY` | 발행 | **0** (신호등 미확정) | 정지 |
| `ENGAGED` | 발행 | 상한 × 100 % | **주행** |
| `DEGRADED` | 발행 | 상한 × 프로파일 비율 | **주행** |
| `STOPPED` | **중단** | 0 | 정지 (복구 중) |
| `SHUTDOWN` | 정차까지 발행 | **0 즉시** | 정지 → 프로세스 종료 |
| `TERMINATED` | **영구 차단** | 0 | 정지 (프로세스 유지) |

> **차가 움직임 = `enable` 있음 AND `speed_limit` > 0.** 둘 중 하나만 봐도 절반은 앎.

<br>

## 핵심 토픽 8개

| 토픽 | 발행 | 주기 | 이 값이 이상하면 |
| --- | --- | --- | --- |
| `/state_machine/enable` | supervisor | 20 Hz | 끊기면 **250 ms 뒤 정지** |
| `/state_machine/speed_limit` | state_machine | 20 Hz | 0 이면 정지. 끊겨도 250 ms 뒤 0 |
| `/state_machine/system` | supervisor | 20 Hz | 위 표와 대조 |
| `/state_machine/mission` | state_machine | 20 Hz | `READY`/`DRIVING`/`FINISHED` + `s_mono` |
| `/state_machine/profile` | **supervisor** | 20 Hz | **축소 주행 여부의 유일 원천** |
| `/diag/heartbeat` | 전 노드 | 10 Hz (계약 19) | `node_id` 별 `status` + `inputs[]` |
| `/perception/start_permission` | object_detection | 10 Hz | **`std_msgs/Bool`**. 출발 전에만 의미, 이후 latch |
| `/path/local` | local_path_planner | **미정** | 빈 경로 = 회피 불가 → `STOP_AND_WAIT` |

<br>

## 임계값 6개

| 항목 | 값 | 의미 |
| --- | --- | --- |
| Deadman timeout | **250 ms** | `enable`·`speed_limit` 공통. 발행 주기 20 Hz 의 5배 |
| 타 노드 stale 임계 | **미정** | 각 노드 동작 주기 실측 후 산출 (`08` section 4-0) |
| 이상 확정 | **연속 3 tick (150 ms)** | 위험 방향은 빠르게 |
| 정상 복귀 | **연속 10 tick (500 ms)** | 안전 방향은 느리게 |
| Emergency 총 지연 | **400 ms** = 150 + 250 | 2.0 m/s 에서 **80 cm** |
| 감시·평가 tick | **20 Hz** (50 ms) | 두 노드 공통 |

<br>

## 증상 → 확인 순서

### 차가 출발하지 않는다

```
1. /state_machine/enable 발행되나?
     안 됨 → /state_machine/system 확인 → INIT(기동 미완) / STOPPED / TERMINATED
              → /diag/heartbeat 에서 어느 node_id 가 status != OK 인지
2. /state_machine/speed_limit == 0 인가?
     그렇다 → /state_machine/mission == READY → 신호등 미확정
              → /perception/start_permission 의 data 가 true 인가?
                 false 또는 미수신 → object_detection 소관 (GREEN 5프레임 연속)
                         State Machine 은 재판정 안 함 (계약 52)
3. 둘 다 정상인데 안 나감 → 컨트롤러 /speed 확인 → 차량 IF 문제
```

### 주행 중 갑자기 섰다

```
1. /state_machine/system 이 STOPPED 인가?
     그렇다 → 로그 events.jsonl 에서 직전 등급 전이 레코드
              → 어느 node_id 가 FAULT 로 확정됐는지 + 근거(age/gap 실측값)
2. STOPPED 가 아닌데 섰다 → /state_machine/speed_limit 값 확인
     0 이면 → Behavior == STOP_AND_WAIT (회피 경로 없음) 또는 `speed_limit = 0` 정지
3. 둘 다 정상 → Deadman 만료 의심 → enable 발행 간격 로그(tick_stats.jsonl)
```

### 라바콘을 못 피했다

```
1. OBSTACLE 이벤트 진입했나?  /state_machine/mission 의 active_event
     안 함 → /perception/objects 에 index 가 떴는지
             → 떴는데 진입 안 함 = 경로 간섭 판정 실패 (05 section 6)
             → 안 떴으면 object_detection heartbeat 의 inputs[] (카메라 stale?)
2. 진입은 했는데 못 피함 → /state_machine/profile 확인
     global_only 였다면 → 차선 미관측 상태. 이탈 허용 범위 확인 (06 section 4-2)
3. /path/local 이 빈 경로였나 → STOP_AND_WAIT 로 갔어야 정상
```

### 어느 노드가 문제인지 모르겠다

```
/diag/heartbeat 하나만 보면 된다 (단일 토픽, node_id 로 구분)
  · status         노드 자체 진단
  · loop_period_max_ms   튀는 노드 찾기 (평균은 정상인데 최대가 크면 초기 징후)
  · inputs[]       입력 stale → 이 노드가 아니라 상류가 원인
  · seq            0 으로 되돌아갔으면 재시작한 것
```

<br>

## 오판하기 쉬운 것 4가지

| 관측 | 오해 | 실제 |
| --- | --- | --- |
| `/perception/objects` 가 0개 | 검출 고장 | **정상**: 라바콘 6개뿐이라 대부분 구간이 0개 (`02` section 5-3) |
| 노드 2개가 동시에 입력 stale | 노드 2개 고장 | **센서 원인**: 재시작해도 소용없음 (`02` section 6) |
| 재시작 직후 하위 노드도 이상 | 연쇄 고장 | **억제 구간**: 판정을 미루는 중 (`03` section 7) |
| `DEGRADED` 인데 `/state_machine/profile` 이 평시 | 어느 쪽이 맞지 | **`/state_machine/profile` 이 진실** (`04` section 3-2) |

<br>

## 안전 불변식. 깨지면 즉시 중단

| # | 불변식 |
| --- | --- |
| 1 | 발행은 **평가 tick 안에서만**. 별도 타이머 금지: 루프가 멈추면 발행도 멈춰야 검출된다 |
| 2 | 정지 수단은 `/state_machine/enable` 과 `/state_machine/speed_limit` **2개뿐**. 새 채널 금지 |
| 3 | 두 컨트롤러의 `deadman_timeout_ms` **동일값**. 다르면 반쪽 명령 |
| 4 | 미검출·미수신의 기본값은 **정지** (화이트리스트 판정) |
| 5 | 속도는 **구간 상한 대비 비율**. 절대값은 구간 상한 하나뿐 |

├── events.jsonl        상태·등급 전이 (매 tick 아님)

├── faults/*.jsonl      FAULT 시 링버퍼 30 s 덤프
└── {node}.out          노드별 stdout/stderr
