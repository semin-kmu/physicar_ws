# `v_min` / `v_max` 변경 체크리스트

`kau_control/config/speed_controller.yaml` 의 `speed.v_min` / `speed.v_max` 를 바꿀 때
같이 손봐야 하는 파라미터 목록.

---

## 0. 핵심 불변식

```
look_k    = look_max_cm / v_max                 [cm per (m/s)] = 전방 시간지평 [s]
kappa_ref = margin * kappa_max                  kappa_max = tan(max_steer)/wheelbase
R_ref     = 1 / kappa_ref                       이 반경에서 v_min
a_lat     = v_min^2 * kappa_ref * 100           [m/s^2] 역산값. 실측 아님
R_sat     = (v_max / v_min)^2 * R_ref           [cm] 이 반경 이상에서 v_max
```

**속도곡선의 모양은 절대값이 아니라 `v_max/v_min` 비율과 `margin` 으로만 정해진다.**
둘을 같은 배율로 올리면 모양은 그대로고 전체가 평행이동한다.

**`margin` 방향 주의** — 내릴수록 *더 완만한* 곡선에서 감속한다.

| `margin` | `R_ref` | 의미 |
| --- | --- | --- |
| 1.0 | 49.45 cm | 차량 최소회전반경에서만 최저속 |
| 0.8 | 61.8 cm | |
| 0.6 | 82.4 cm | 완만한 곡선에서도 최저속 |

## 1. `kau_control` — `speed_controller.yaml`

| 파라미터 | 수정 방법 | 근거 |
| --- | --- | --- |
| `look_max_cm` | **`= v_max * 100`** | 지평 1.0 s 유지. `look_k = look_max/v_max` |
| `min_span_cm` | 유지 | 바닥이 걸리는 속도 = `(look_min+min_span)/look_k` |
| `margin` | 트랙 곡률로 판단 | §0 표. 트랙 원호는 §5 |
| `use_sqrt_law` | 유지 (`true`) | 중속 구간을 올리려면 `false` (선형) |
| `accel_max` / `decel_max` | 유지 | 속도 폭이 좁으면 `ema_tau` 가 항상 더 느려 미작동 |
| `ema_tau` | 유지 | 지평이 `2.5 * ema_tau` 초 미만이면 코너 진입 초과속 발생 |

**지평 하한** — `look_max_cm / v_max / 100 >= 2.5 * ema_tau` 를 만족할 것.
현재 1.0 s vs 1.0 s 로 경계. 미달이면 `look_max_cm` 을 올리거나 `ema_tau` 를 내린다.

## 2. `kau_control` — `steer_controller.yaml`

| 파라미터 | 수정 방법 | 근거 |
| --- | --- | --- |
| `ld_min_cm` | **`k_v * v_min * 100 < ld_min_cm` 이면 `Ld` 가 고정된다** | 아래 |
| `ld_max_cm` | `k_v * v_max * 100 > ld_max_cm` 이면 상한에 물림 | |
| `k_v` | 위 두 조건을 벗어나면 죽은 손잡이 | |

```
Ld = clamp(k_v * v, ld_min_cm, ld_max_cm)
```

`Ld` 가 고정돼도 즉시 고장은 아니다. 코너컷 오차 `Ld^2 / (8R)` 로 판단할 것.
현재 `Ld` 30 cm 고정, R 63 cm 코너에서 오차 1.8 cm — 허용.

## 3. `kau_local_path_planner` — `local_planner.yaml`

| 파라미터 | 수정 방법 | 근거 |
| --- | --- | --- |
| `validated_horizon_cm` | **아래 식 × 1.5** | 제어기가 보는 점을 hard gate 안에 넣는다 |
| `l_plan` / `preview` | 시간환산 검토 | `l_plan / v_max` 가 과하면 먼 기하에 끌림 |
| `anchor_max_age_sec` | 유지 | |
| `plan_hz` | 유지 | |

```
필요 = max(k_v * v_max * 100, ld_min_cm) + 100 * v_max / plan_hz + 5   [cm]
```

- **하한 35 cm** — 제어기는 `usable < ld_min_cm` 이면 정지한다.
- 올릴수록 후보 탈락이 늘어 `st=1`(degraded) 비율이 오른다.
- **변경 후 로그의 `st=` 분포를 반드시 재측정할 것.**

## 4. `kau_lane_detection` — `lane_detection.yaml`

| 파라미터 | 수정 방법 | 근거 |
| --- | --- | --- |
| `pan_aim_lookahead_m` | **`<= 2 * R_min * rad(pan_max_deg)`** | 넘으면 전 코너에서 포화 |
| `pan_rate_deg_s` | `>= psi_max / (d / v_max)` | 코너 진입 전이 추종 |
| `pan_aim_gain` | 유지 (1.0) | `d` 와 곱으로만 작용 |

```
조준각 psi = d / (2R)   [rad]     d = pan_aim_lookahead_m, R = 곡률반경
```

`R_min` = 49.45 cm, `pan_max_deg` = 30 -> `d <= 0.518 m`.

`psi > pan_max_deg` 면 카메라가 기계한계에 붙박이가 되어 비례제어가 무의미해진다.
**`d` 를 `v_max * 1.0 s` 로 두면 `look_max_cm` 과 같은 지평이 되어 일관된다.**

## 6. 손댈 필요 없는 것

**파생값** — 코드가 매 tick 유도: `a_lat`, `kappa_ref`, `R_sat`

**모든 시간 기반 타임아웃** — 속도를 내리면 거리로는 오히려 보수적이 된다.
`path.sources.*.timeout` (local / global / lane), `anchor_max_age_sec`,
`track_timeout_s`, driver `cmd_timeout`

**`cte_abort_cm`, `goal_tol_cm`** — 속도 무관.
