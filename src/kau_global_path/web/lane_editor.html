세그먼트

Ctrl+클릭(또는 노드 위에서 C)으로 노드를 세그먼트 경계로 만든다 — 경계는 ■, 안쪽 노드는 ●다. 경계와 경계 사이가 quintic Bezier 한 조각(제어점 6 개)이고, 그 사이 노드 수로 종류가 정해진다.
노드 2 개직선 — κ=0. 정확히 직선이 나온다.
노드 3 개원호 — 세 점의 외접원. 가운데 노드로 곡률을 직접 조정.
노드 2 개 + 전이전이 — 양 끝 (θ,κ)를 이웃에서 받는다.
노드 4 개+보간 — 예전 방식으로 안에서 다시 쪼갠다.
경계를 하나도 안 찍으면 예전 그대로 — 전체를 한 덩어리로 보간한다.

C² 검증

허용오차 deg 1/m
직선(κ=0)과 원호(κ=1/R)는 맞닿아 있는 한 절대 C² 가 될 수 없다. 평균으로 강제하면 C² 는 되지만 직선이 살짝 휜다. 직선을 정확히 남기려면 직선과 원호 사이에 노드 2 개짜리 전이 세그먼트를 하나 두는 쪽이 낫다 — 아래 목록에서 전이로 를 누르면 된다.

Boundary 생성

차선 중심선을 법선 방향으로 밀어서 트랙 경계를 만든다. Object Detection ROI 는 outer 안쪽 ∩ inner 바깥쪽 고리다.
CAD 실측값이 자동으로 들어온다 (중심선에서 양쪽 0.354 m). center 엣지의 width 로 나간다.
차로를 둘로 나눌 때만 쓴다 (지금 경로에는 안 쓴다). boundary 생성 간격도 이 값이다.

검사 — 곡률 한계

휠베이스 L m 최대 조향 δ °
마진
—
쓰는 한계 κ 1/m
kinematic bicycle model, 후륜축 중심 기준: R = L / tan δ · κ = tan δ / L. 한계를 넘는 세그먼트는 캔버스에서 빨갛게 그려진다. 위 세 값을 바꾸면 한계가 다시 계산되고, 한계 칸을 직접 고치면 그 값이 이긴다.
